# AI伏せ字ガード

ChatGPT・Claude・Gemini に送る前に、日本語の個人情報を【氏名1】のような記号に自動で置き換える Chrome 拡張機能です。AIの返答に出てきた記号は、あなたの画面でだけ元の値に戻して表示します。

- 処理はすべて端末内。外部へは一切送信しません
- 広告・アクセス解析・トラッキングなし
- 権限は `storage` と、対応する3つのAIサイトだけ

## できること
1. 入力中の文章から個人情報らしき箇所を見つけ、下線と件数を表示します
2. 送信（Enter キーまたは送信ボタン）の直前に、該当箇所を記号に置き換えてから送信します
3. AIの返答や自分の送信済みメッセージに出てくる記号を、画面上で元の値に戻して表示します
4. 返答のコピーボタンを押すと、元の値に戻した文章がコピーされます

## 見つける情報
| 種類 | 方法 |
|---|---|
| マイナンバー・法人番号 | 桁数とチェックデジットで確認 |
| クレジットカード番号 | Luhn で確認 |
| 電話番号・メールアドレス・郵便番号・住所 | パターン（全角数字やハイフンの違いも吸収） |
| 氏名 | 「氏名：」「担当：」などの項目名、「〇〇様」などの敬称 |
| 登録語 | 社名・顧客名・案件名など、設定画面で登録した語 |

## 知っておいてほしいこと
- 送信前の「うっかり」を減らす補助ツールです。すべての個人情報を確実に見つけられるわけではありません
- ファイル・画像のアップロードや音声入力の内容は対象外です
- 記号と元の値の対応表は、ブラウザを閉じると消えます

## 権限
| 権限 | 理由 |
|---|---|
| `storage` | 設定・登録語（端末内）と、記号の対応表（ブラウザを閉じると消える領域）を保存する |
| chatgpt.com / claude.ai / gemini.google.com | 入力欄の文章を送信前に伏せ字にし、返答の記号を元に戻して表示する |
